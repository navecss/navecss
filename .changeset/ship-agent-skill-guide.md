Ships `skills/navecss/SKILL.md`, an Agent Skills guide generated from the atom source and the resolved token/palette data: every built-in atom with its declarations and variants, every `--nave-*` custom property with its description where one exists, the `@layer` order, and the `@nave`/`cx()`/`cx.raw()` idiom. No coding agent discovers a file under `node_modules` on its own, so reach it through a pointer block in your project's `AGENTS.md` (documented in a later change) rather than expecting it to load automatically.
