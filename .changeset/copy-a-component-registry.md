Ship a shadcn registry of the components the package styles. `dist/registry/` holds one item for each styled component and a `registry.json`, generated by the build from the same source as the package. `npx shadcn add ./node_modules/@navecss/base-ui/dist/registry/base-ui-dialog.json` copies a component's files into a project that has no Tailwind and no `components.json`, and the copy's rules can then be changed in the copy. The package's exports, wrappers and stylesheet are unchanged. See "Copy a component into your project" in the README.
