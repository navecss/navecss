Ships `@navecss/eslint-plugin`, a NaveCSS plugin for ESLint®. Four rules close the JSX escape hatches nothing checked before: `@navecss/class-channel` (a literal class in `className`/`class` must be declared or a real `cx()` atom), `@navecss/raw-reason` (a `cx.raw()` call carrying undeclared class text needs a reason comment), `@navecss/count-escapes` (off by default; feeds ESLint's own bulk-suppressions file), and `@navecss/style-values` (a literal value on a JSX `style` property the design system tokenizes).
